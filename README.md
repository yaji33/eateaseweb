# EatEase: A Decentralized Eatery Web Platform For Restaurants Featuring Local Eateries (Admin & Business Dashboard)

## Overview
This is the web application for the decentralized eatery platform, built using **React**.  
It allows businesses (primarily restaurants) to manage their profiles, menus, and orders,  
while admins oversee the platform and manage eateries.

---

## Key Features

### **1. Business Onboarding & Setup**
A guided onboarding flow ensures restaurants are fully ready for launch:
- Complete business profile (address, contact details, hours).
- Add menu items with categories.
- Submit verification documents for approval.
- Publish the business to be visible to customers.

---

### **2. Restaurant Dashboard**
A data-driven overview of business performance, including:
- **Total Revenue**
- **Total Orders**
- **Average Order Value**
- **Customer Ratings**
- Revenue trends over time.
- Order volume breakdown.
- Peak hours for sales.
- Top-selling menu items.

---

### **3. Order Management**
- View and manage incoming orders in real time.
- Update fulfillment status (e.g., pending, preparing, completed).
- Maintain an organized order history.

---

### **4. Menu Management**
- Create and edit menu items with pricing, descriptions, and categories.
- Organize menus for easy navigation by customers.

---

### **5. Transactions & Payments**
- Track all transactions and settlement history.
- View payment details and reconcile revenue data.

---

### **6. Profile & Communication Tools**
- Update restaurant information and operational details.
- Built-in messaging for communication between restaurants and admins/customers.
